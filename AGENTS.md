# Repository guidance

- The Rust API is in `backend/` (Cargo workspace at the root); the React + TypeScript/Vite app is in `frontend/`.
- Local stack: start PostgreSQL with `docker compose up -d db` (host port 5433), run the API from the repository root with `cargo run -p offre-taf-api`, and run the UI from `frontend/` with `npm run dev`.
- The API reads root `.env`, creates/updates its `jobs` table at startup, and serves `GET /api/jobs?q=...`, `GET /api/jobs/summary`, `GET /api/jobs/unread-count`, `PATCH /api/jobs/{id}/read`, `PATCH /api/jobs/{id}/favorite` plus `/health` on `API_ADDR` (default port 3000). The Vite UI runs on port 5173 and calls the API directly.
- Frontend production/type check: run `npm run build` from `frontend/`; backend verification: `cargo check --workspace` and `cargo test -p offre-taf-api` from the root.
- The product has three views: IT jobs in Burkina Faso taken from employers' own sites, remote jobs (with the zone they can be done from), and jobs mentioning relocation/visa. Listings mentioning Java are favourited automatically; users can add/remove favourites manually.
- Sources are registered in `sources::schedule()` / `sources::collect()` (`backend/src/sources.rs`). The API polls all sources immediately at startup; Arbeitnow repeats every `COLLECT_INTERVAL_MINUTES` (default 60), Remotive every 360 minutes (respect its max-four-calls/day guidance), Wave/Yassir/Gozem/Djamo every 360 minutes, EntreprisesATS (Greenhouse/Lever/Ashby boards in `sources/ats.rs`), Workable and BurkinaEntreprises (WordPress employer sites in `sources/burkina.rs`) every 720 minutes, and OpenToAfrica, EmploiDakar, BFemploi, SABMA and Qualive daily.
- Text heuristics (IT role, Java, relocation, remote scope) live in `backend/src/sources/classify.rs` and are applied centrally in `save_job`. Direct francophone connectors and their country allowlist are in `backend/src/sources/francophone.rs`; preserve original job links and filter by explicit country/location mentions. OpenToAfrica dates come from relative homepage labels; listings older than 180 days are pruned. Non-favourite listings not seen for 21 days by a successful run of their source are pruned. Source failures are logged without stopping the API. Unread alerts are stored in `jobs.is_read`, favourites in `jobs.is_favorite`.
